Dice Roll Simulator

Personal

Built an interactive web application using R Shiny that simulates dice rolling experiments and visualizes the resulting probability distributions in real time. The app allows users to adjust the number of rolls (up to 10,000) and the number of dice (up to 10) using sliders, select between fair or biased dice using a dropdown menu, and optionally overlay a normal distribution curve to observe convergence. A summary statistics table displaying mean, median, standard deviation, minimum, and maximum updates dynamically with each simulation. The app demonstrates the Central Limit Theorem in action — as the number of dice increases, the distribution of summed rolls visibly shifts from uniform to bell-shaped. Deployed publicly on shinyapps.io. Skills demonstrated: R, Shiny, ggplot2, probability theory, statistical simulation, interactive data visualization, web deployment.

R · Shiny · ggplot2
